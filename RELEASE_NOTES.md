## Скачать

* **Windows 10/11** — `iOSPanicReader.exe`. Нужен драйвер Apple: приложение «Apple Devices» из Microsoft Store (или iTunes).
* **Mac (M1 и новее)** — `iOSPanicReader-macOS.zip`. Распакуйте, перенесите `iOSPanicReader.app` в «Программы», первый запуск: правый клик → «Открыть» → «Открыть».

## Что нового в 0.3.0 — окно и масштаб

* Правильный вид на экранах с масштабом Windows 125–200%: отступы, строки таблиц и график растут вместе с текстом
* Масштаб интерфейса: кнопки «− 100% +» справа вверху, или Ctrl + / Ctrl − / Ctrl 0 (на Mac — ⌘)
* Текст перестраивается при изменении размера окна; на узком окне колонки встают одна под другую, верхнее меню ужимается
* Окно запоминает размер, положение, развёрнутость и масштаб; если монитор сменился — открывается по центру
* Дополнительные окна (ремонт, исходный лог) открываются по центру программы, закрываются по Esc
* Горячие клавиши: Ctrl 1…5 — вкладки, Ctrl O — открыть файл лога
