## Скачать

* **Windows 10/11** — `iOSPanicReader.exe`. Нужен драйвер Apple: приложение «Apple Devices» из Microsoft Store (или iTunes).
* **Mac (M1 и новее)** — `iOSPanicReader-macOS.zip`. Распакуйте, перенесите `iOSPanicReader.app` в «Программы», первый запуск: правый клик → «Открыть» → «Открыть».

## Что нового

* «Отметить ремонт»: после ремонта показываются только новые сбои, можно стереть старые логи на телефоне
* Вкладка «История»: все телефоны, визиты, ремонты, заметки
* PDF-отчёт для клиента с названием мастерской
* График паник по дням
* «Показать логи этой детали» из карточки проблемы
