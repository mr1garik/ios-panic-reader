## Что нового в 0.4.3

* **Новый интерфейс** — тёмная тема «Неон», боковое меню, заставка. Сверху — данные телефона (модель, iOS, разъём, Face ID / Touch ID, аккумулятор)
* **Вероятность по деталям** — «Шлейф зарядки 94%», по клику — почему столько
* **Группы ошибок** со счётчиками («17/25»), клик открывает логи группы
* **Где искать на плате** — у каждой проблемы зона телефона на схеме и что проверить
* **Исходный лог с подсветкой** найденных строк и датчиков
* **Своё описание ошибки** — у любого лога: что помогло. Программа сразу начнёт узнавать такую панику; можно отправить в общую базу
* **Сообщить об ошибке программы** (кнопка 🐞) — версия, система и журналы без личных данных
* **TXT-отчёт** в папке каждого телефона и в «Истории»
* **Очистка логов на телефоне** — после ремонта видны только новые сбои
* **Разные экраны** — окно не заходит под панель задач и Dock, масштаб Windows 100–300%, небольшие ноутбуки
* Названия iPad, подсказки по датчикам с учётом модели (Lightning / USB-C)
* Обновление работает, даже если GitHub ограничил запросы
* Исправлено: зависание при открытии лога с длинным текстом
* Поддержать проект: USDT (TRC20) и QR-код в окне «О программе»

Если новое окно не может запуститься (нет WebView2 на старой Windows 10), программа откроется в прежнем виде.

## Скачать

* **Windows 10/11** — установщик `iOSPanicReader-Setup.exe` или портативный `iOSPanicReader.exe`. Нужен драйвер Apple: «Apple Devices» из Microsoft Store (или iTunes).
* **Mac (M1 и новее)** — `iOSPanicReader-macOS.zip`. Распакуйте, перенесите в «Программы», первый запуск: правый клик → «Открыть» → «Открыть».

Если у вас уже стоит 0.4.2 — программа сама предложит обновиться при запуске. Ваши данные не изменятся.
